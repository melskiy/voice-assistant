# Product Overview

## Voice Assistant Core

A modular voice assistant system designed for Russian language processing with pluggable ASR, NLU, and TTS engines. Built for integration with FreeSWITCH telephony systems.

## Key Features

- **Offline Operation**: All processing works without internet connectivity
- **Russian Language Optimized**: Specifically designed for Russian voice processing
- **Pluggable Architecture**: Swap ASR, NLU, and TTS engines without code changes
- **Microservices Architecture**: Containerized services for scalability
- **FreeSWITCH Integration**: Ready for telephony system integration

## Core Capabilities

- **Speech Recognition**: Vosk (lightweight) and Whisper.cpp (accurate) engines
- **Natural Language Understanding**: Regex-based and ML-based intent classification
- **Text-to-Speech**: Silero TTS for high-quality Russian speech synthesis
- **Task Management**: Shopping lists, reminders, and todo management
- **Real-time Processing**: Optimized for voice call scenarios with low latency

## Target Use Cases

- Voice-controlled todo list management
- Telephony-based voice assistants
- Offline voice processing systems
- Russian language voice applications
